# Tiny-Tools

⚡ **Make Everything Smaller, Faster, Better**

Tiny-Tools is the ultimate free toolkit for digital optimization. Shorten URLs, compress images, and minify documents - all in one powerful platform.

## Features

- **URL Shortener** - Create short, memorable links instantly
- **Image Optimizer** - Compress images without losing quality
- **Document Minifier** - Reduce document file sizes efficiently

## Why Tiny-Tools?

- ⚡ **Lightning Fast** - Process your files in seconds
- 🔒 **Secure & Private** - Files are processed securely and never stored
- 🎉 **Always Free** - No hidden costs, limits, or premium tiers

## Technologies

This project is built with:

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
- Supabase

## Getting Started

### Prerequisites

- Node.js & npm installed - [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating)

### Installation

```sh
# Clone the repository
git clone https://github.com/MonarCat/Tiny-tools.git

# Navigate to the project directory
cd Tiny-tools

# Install dependencies
npm install

# Start the development server
npm run dev
```

The application will be available at `http://localhost:8080`

## Available Scripts

- `npm run dev` - Start the development server
- `npm run build` - Build for production
- `npm run build:dev` - Build for development
- `npm run preview` - Preview the production build
- `npm run lint` - Run ESLint
